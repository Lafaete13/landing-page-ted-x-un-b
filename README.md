# TEDx Universidade de Brasília - Vários Futuros 🔴

Landing page oficial e sistema de credenciamento para o evento **TEDx UnB: Vários Futuros - Pluriverso de Narrativas Fundadoras**. 

O projeto apresenta os palestrantes, informações do evento e conta com um sistema dinâmico para inscrição de participantes e geração de ingressos personalizados na hora.

## 🚀 Funcionalidades

* **Design Responsivo:** Layout adaptável para mobile e desktop, seguindo a identidade visual limpa e minimalista do TEDx.
* **Modal de Palestrantes:** Interface interativa para visualização das biografias (com tratamento anti-estouro em telas pequenas).
* **Sistema de Credenciamento:** Formulário integrado para inscrição de alunos da UnB e comunidade externa.
* **Geração de Ingressos:** Renderização do ingresso em tempo real no navegador utilizando o nome e o QR Code retornado pela API.
* **Exportação HD:** Opção de download do ticket em **PNG** ou **PDF** em alta resolução.

## 🛠️ Tecnologias Utilizadas

* **Next.js / React:** Framework principal e componentização.
* **Tailwind CSS:** Estilização rápida e criação do design system.
* **html2canvas & jsPDF:** Captura do DOM e conversão para download do ingresso.
* **Lucide React:** Biblioteca de ícones.
